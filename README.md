# Stratview One

Stratview One is a React and TypeScript application for browsing market research dashboards and dataset-driven views.

## Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Redux Toolkit
- Vitest

## Requirements

- Node.js 18 or newer
- npm 9 or newer

## Local development

```sh
npm install
npm run dev
```

The Vite dev server runs on port `8080` by default.

## Build and preview

```sh
npm run build
npm run preview
```

## Tests

```sh
npm test
```

## Project structure

- `src/` contains the application source code.
- `public/` contains static assets and market data JSON files.
- `import_templates/` contains import and integration reference material.
